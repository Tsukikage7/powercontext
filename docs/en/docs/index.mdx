Start with Quick Start to configure full memory and the Dashboard, using Generation and Embedding model APIs.
Without separate model APIs, choose basic memory to test explicit saves and recall.
This site's commands use the default `oceanbase/powercontext` installation; keep the Server and plugins on that same source and ref.

Platforms: macOS, Linux; Windows `experimental`. See [installation](get-started/install-and-run.md) for version selection.

Use the site search to find pages in the current language. Choose **User docs** for setup, integrations, workflows, operations, and API usage guides; **Development** for contributing to PowerContext; or **RFCs** for design proposals. **All** searches all three, showing user docs first. Changing the scope keeps your search terms, and a search with no results in one scope offers **Search all documents**.
